# OpenGiraffe Java Task Packets

这些文件是 `docs/java-opengiraffe-prd.md` 的可执行任务包拆分版，用于逐个投喂给 OpenGiraffe。

使用方式：

```text
请完成 `docs/tasks/task-XX-*.md` 中定义的任务。
开始前必须阅读该 task packet；如果可以，也要阅读 `docs/java-opengiraffe-prd.md`。
只实现该 task packet 的范围，不要顺手实现后续任务。
```

每个 task packet 都包含：

- 系统背景
- 必读上下文
- 本次任务目标
- 关键约定
- 禁止事项
- 验收标准

注意：这些文件必须提交到目标 Java 项目仓库，否则 OpenGiraffe 创建 git worktree 时可能读不到它们。
